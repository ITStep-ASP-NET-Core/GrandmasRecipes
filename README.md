*Останнє оновлення: 07.03.2026*

---

## 📌 Загальна інформація

### **Тема**

Веб‑проєкт **«Кулінарний блог»**

### **Опис проєкту**

Веб‑додаток для пошуку кулінарних рецептів найпопулярніших кухарів світу.

Користувачі зможуть:

* знаходити рецепти зі **своїх наявних продуктів**;
* готувати **прості та смачні страви**;
* дивитися **відео‑гайди** та готувати разом із кухарями.

### **Мета проєкту**

Створення платформи, яка **спрощує пошук рецептів** на основі продуктів, що вже є у користувача.

# 🧑‍🍳 Управління рецептами

### Оцінювання

Користувачі можуть оцінювати існуючі рецепти.

### Коментарі

Можливість залишати коментарі до рецептів.

### Відео‑гайди

Можна додати посилання на відео кухаря, який готує за цим рецептом.

### Створення рецепта

Користувач може створити новий рецепт з:

* текстом
* розділеними кроками
* медіафайлами (зображення, відео, аудіо)

### Редагування рецепта

Можливість змінювати вміст рецепта.

### Видалення рецепта

Користувач може видаляти свої рецепти.
